# GameReserve

A modular monolith backend for managing games, reservations, users, and payments.

GameReserve is a project built with modern .NET technologies and software engineering practices.

The project is designed to explore modular architecture, domain-driven design, clean code, reliable communication, automated testing, and production-oriented backend development.

## Current Status

**Early development**

The project is currently being built from the ground up.  
Architecture, modules, infrastructure, and features will be introduced incrementally.
